# JARVIS
JARVIS is an AI-powered futuristic desktop assistant built with Python, Groq, and Whisper, featuring voice commands, automation, phone integration, WhatsApp control, and a cyberpunk-inspired UI.

🤖 JARVIS — AI Desktop Assistant

JARVIS is a futuristic AI-powered desktop assistant inspired by Iron Man’s virtual assistant system. Built with Python, Groq LLMs, Whisper STT, and offline TTS, it combines voice interaction, automation, phone integration, and a cyberpunk-inspired UI into one intelligent assistant platform.

✨ Features
🎙 Wake-word voice activation
🧠 AI conversation using Groq LLM
🔊 Offline text-to-speech support
📝 Speech-to-text with Whisper
📱 Android phone integration via ADB
☎ Incoming call detection & control
💬 WhatsApp messaging automation
📂 File & folder management
🌐 Browser & YouTube controls
📸 Screenshot capture
⚡ Real-time animated cyberpunk HUD UI
🖥 System telemetry dashboard
